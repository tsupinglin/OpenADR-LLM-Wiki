# OpenADR × EnergyPlus LLM Wiki Teaching Project

## 檔案
- `index.html`：專案首頁
- `wiki.html`：LLM Wiki 成果
- `presentation.html`：教學 HTML 簡報
- `workflow.html`：loop / graph、執行紀錄、反思
- `wiki/`：6 個 Wiki Markdown 節點
- `data/sources.json`：6 篇 ingest 資料清單
- `submission.md`：可直接整理到繳交區的文字

## GitHub Pages
將所有檔案上傳 Repository 根目錄。
Settings → Pages → Deploy from a branch → main → /(root)。

部署後：
- `/wiki.html`
- `/presentation.html`
- `/workflow.html`
